## 3. 순차 실행 순서와 승인 기준

1. **1단계 — 원본 감사·회귀선 확보 [완료]**: ZIP 88파일 해제, API·DB·템플릿·등록증 비노출·이미지·기존 `pytest` 7개 통과 확인. 기준선 기록.
2. **2단계 — 운영 보안 [완료/로컬]**: 계정 중지, 비밀번호 변경 시 세션 차단, 초기가입 로컬 제한, 관리자 캐시 차단, 악성 CSV 수식 접두어 방어. *합격:* 비활성 계정 및 구 세션의 관리 접근 401.
3. **3단계 — CRM/허브 고도화 [완료/로컬]**: 후속업무 추가·우선순위·일자·담당자·상담 연결, CSV 내보내기 및 마감 지표. *합격:* 생성·상태변경·삭제·권한·중지 처리 HTTP/SQLite 확인.
4. **4단계 — 콘텐츠/개인정보·마이그레이션 [부분 완료]**: 개인정보 초안, 보유기간 및 안전한 수동 정리, Blogger 임시글 미리보기, 기존 데이터 보존. *합격:* 마이그레이션·미리보기·모의 API 테스트 및 개인정보 미리보기 후 선택 실행. *미결:* 운영자 법률 검토와 실제 OAuth.
5. **5단계 — UI·회귀·패키징 [완료/오프라인]**: PC/모바일 총 12화면 오프라인 Chromium 검증, `pytest` 14개 합격, 깨끗한 소스 ZIP 재검수. Windows 실기기 시험은 별도.
6. **6단계 — Google·운영 서버 연결 [외부 승인 필요]**: Google OAuth/Blogger 블로그·Search Console 소유권, 공개 도메인, HTTPS, 관리자 2FA 설정·법률 문구 확정. *합격:* 테스트 블로그에 임시글 생성 후 ID 확인; 운영 서버 HTTPS 통과; 개인정보처리방침 확정.
7. **7단계 — 유료 예약/정산 상용화 [사업 계약 필요]**: 예약 사업자/PG 계약, 상품별 견적·계약/취소/환불, 공급사 예약 검증, 복구·부하·보안 심사. *합격:* 테스트 결제·환불, 예약 일치, 동시성, 감사기록 및 복구 리허설.

## 4. 사용자에게 필요한 외부 입력 / 운영 승인

- Google Blogger **블로그 ID, OAuth 사용 승인**(앱 권한 scope `https://www.googleapis.com/auth/blogger`), 운영할 Blogger 계정에서 테마 실제 설치 허용.
- 배포할 도메인/서버(HTTPS), DNS/Search Console 소유권 인증. 개인정보 접근권한·서버 저장 위치 결정.
- 개인정보 보유기간, 사업 약관, 취소·환불 기준, 광고성 동의 문구, 내부 권한·백업 정책의 운영 책임자 승인.
- 차량·숙박·항공·견학 기관·결제 PG 사업자 및 계약·API 자격증명. 공개 전 실제 관광등록 상태·상품 약관·실예약 가능 여부 최종 확인.

## 5. 테스트 증거·제한

- 명령: `python -m pytest -q` — **14 passed** (실제 로컬 SQLite 임시 DB, HTTP TestClient와 API 모의 객체 포함). 기존 v1 7개 + 신규 v2 7개.
- 로컬 화면: `python -m scripts.render_visual_check`(4 화면), `python -m scripts.render_v2_check`(8 화면). **총 12건 오프라인 Chromium 무넘침·JS 오류 0**, 신규 후속업무 PC·모바일 입력폼 재수정 후 재검증.
- 테스트 성격: 오프라인 콘텐츠 렌더 검증이며 실제 호스팅 사이트에서 링크를 눌러 전체 브라우저 탐색한 E2E가 아닙니다. 실 Google·실 결제·실 외부 발송·Windows 실기기·실제 고객 데이터는 검증하지 않았습니다.
- 개인정보 안내 초안은 법정 필수 항목이 모두 검토된 정식 처리방침이 아닙니다. 외부 공개 전에 검토·고지와 보안 수준을 보완해야 합니다.

## 6. 실행 명령 및 산출물

```bash
# 압축 해제 후 프로젝트 폴더에서
python -m pip install -r requirements-dev.txt
python -m pytest -q
python run.py                # 기본 127.0.0.1:8787
# 브라우저: /setup → /admin/login → /admin/tasks
python scripts/backup.py    # 운영DB 복사본을 로컬 ZIP에 보관(암호화되지 않음)
python scripts/purge_expired.py            # 삭제 대상 확인만 수행
python scripts/purge_expired.py --execute  # 운영 책임자 승인 후 선택 실행
```

**파일 안내:** `docs/MIGRATION_V1_TO_V2.md`(업그레이드), `docs/OPERATIONS.md`(일일운영), `docs/QA_V2.md`(테스트 판정), `blogger/README.md`(Blogger 준비), `proposals/`(6종 여행제안서). ZIP에는 운영 비밀번호/실제 상담 DB/세션 암호키를 포함하지 않습니다.
