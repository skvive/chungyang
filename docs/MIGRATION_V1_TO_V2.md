# v1 → v1.1 Beta 데이터 마이그레이션

1. 운영 중인 서버를 완전히 종료합니다. `python scripts/backup.py`로 일관성 백업을 생성하여 별도로 보관합니다.
2. 백업본 및 `data/cheongyangplus.db`, `data/session_secret`를 안전한 비공개 위치에 보관합니다. 백업 ZIP을 웹 공개 경로에 올리지 마세요.
3. 새 소스 코드 폴더의 `data/`에 **기존 DB와 session_secret**을 복사합니다. 사용자·고객 데이터가 포함되므로 원본은 별도 보관하세요.
4. 첫 실행 시 `db.init()`이 `users.active`, `users.auth_version`, `tasks` 및 후속 인덱스를 부가합니다. 기존 사업자/상담/상품 데이터는 보존합니다.
5. `/admin/login` 재로그인 후 기존 상품·상담·제안서 개수를 대조하고, `/admin/tasks`와 `/privacy`의 접근을 확인하세요.
6. 테스트용 ZIP에 실제 DB·세션 키가 포함되지 않도록 확인합니다. 마이그레이션 후 구버전으로 역돌리기보다는 원본 백업 복원을 권장합니다.

**주의:** v1 이전에 모든 상품·게시물이 삭제된 DB도 v1.1에서는 재시드하지 않도록 보호합니다. 최초 설치에만 예시 콘텐츠를 생성합니다.
